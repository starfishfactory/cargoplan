위험물 운송 서비스

MSDS 기반 위험물 분류부터 포장, 서류 작성, 해상·항공 운송까지 전문적으로 관리합니다.

MSDS(물질안전보건자료)란?

MSDS(Material Safety Data Sheet)는 화학물질의 유해·위험성, 취급 방법, 응급 조치, 운송 정보 등을 포함한 안전 정보 문서입니다. 위험물 운송 시 MSDS는 화물의 UN번호, 위험물 등급, 포장 그룹을 결정하는 기본 자료가 됩니다.

위험물 등급 분류 (UN Class)

Class 1 - 화약류

폭발성 물질 및 화약류. 대량 폭발 위험(1.1)부터 둔감한 폭발물(1.6)까지 6개 세부 등급으로 구분합니다.

Class 2 - 가스류

인화성 가스(2.1), 비인화성·비독성 가스(2.2), 독성 가스(2.3)로 구분. LPG, 에어졸, 냉매 등이 해당됩니다.

Class 3 - 인화성 액체

인화점이 낮은 액체류. 페인트, 접착제, 향수, 알코올, 유기용제 등 물류에서 가장 흔한 위험물 등급입니다.

Class 4 - 가연성 고체

가연성 고체(4.1), 자연발화성 물질(4.2), 물반응성 물질(4.3). 금속분말, 활성탄 등이 포함됩니다.

Class 5~6 - 산화성·독성

산화성 물질(5.1), 유기과산화물(5.2), 독성 물질(6.1), 감염성 물질(6.2)로 구분됩니다.

Class 7~9 - 방사성·기타

방사성 물질(7), 부식성 물질(8), 기타 위험물(9). 리튬배터리, 석면, 드라이아이스 등이 Class 9에 해당합니다.

위험물 포장 및 서류 요건

포장 요건

  • UN 인증 포장용기 사용 (UN마크 표기)
  • 포장 그룹(PG I·II·III)에 따른 포장 등급 적용
  • 위험물 라벨(GHS 라벨) 및 표시(Marking) 부착
  • 내부 포장재, 흡수재, 쿠션재 적정 사용

필수 서류

  • MSDS (물질안전보건자료) - 16개 항목 완비
  • 위험물 신고서 (Dangerous Goods Declaration)
  • 위험물 컨테이너/차량 적재 증명서
  • 항공운송 시 Shipper's Declaration for DG

카고플랜 위험물 운송 프로세스

  • 1단계 - 위험물 확인: MSDS 검토 → UN번호·위험물 등급·포장그룹 확인 → 운송 가능 여부 판단
  • 2단계 - 운송 계획: 해상/항공 운송 모드 결정 → 선사/항공사 위험물 접수 가능 여부 확인 → 운임 산정
  • 3단계 - 포장·서류: UN 인증 포장 → 위험물 라벨링 → 위험물 신고서 작성 → 관련 서류 준비
  • 4단계 - 운송·관리: 위험물 전용 보관 → 안전 적재 → 운송 중 모니터링 → 목적지 인도
